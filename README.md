# Sweetch 1.0

Файловый конвертер для Windows с круговым меню. Автор проекта Sweetch: [@mmmorozov](https://t.me/mmmorozov).

> **Это форк.** Оригинальный проект — [krllmrzv/Sweetch](https://github.com/krllmrzv/Sweetch), автор [@mmmorozov](https://t.me/mmmorozov); вся основа программы — его работа. Ссылки на скачивание ниже ведут на релизы оригинала, в них нет функций форка — их нужно собрать из исходников (раздел «Сборка»).
>
> Что добавлено в форке:
>
> - **Смотреть** (меню Alt) — плеер видео и аудио со звуком.
> - **Обрезать** — теперь с плеером: перемотка, шаг по кадрам (←/→), метки начала и конца (I/O); резка точно по кадру на экране.
> - **Кадры** — выбор любого количества кадров в плеере (S), каждый сохраняется в PNG.
> - **Свет и цвет** — экспозиция, контраст, света, тени, яркость, гамма, теплота, оттенок, насыщенность, сочность для фото и видео с живым предпросмотром.
> - **Кодек и FPS** — перекодирование в H.264, H.265, AV1, VP9 или ProRes с любой частотой кадров.
> - **Скорость** — от 0,1× до 16×, звук сохраняет высоту тона.
> - **Простые имена файлов** (настройка) — результаты без пробелов, скобок и кириллицы: `moe_video_obrezano.mp4`.

## Запуск

Установите программу через EXE или распакуйте весь архив ZIP и запустите `Sweetch.exe`. Программа находится в области уведомлений рядом с часами; двойной щелчок открывает настройки.

Язык: **Как в системе / Русский / English**. Для остальных языков системы используется английский. Оформление: **Как в системе / Тёмная / Светлая**. Тёмная тема — красно-чёрная, светлая — бело-голубая.

Настройки хранятся в `%APPDATA%\Sweetch`, загружаемые инструменты — в `%LOCALAPPDATA%\Sweetch\tools`. Скриншоты и виртуальные вложения сохраняются в `Downloads\Sweetch`. Исходные файлы не перезаписываются.

## Форматы

Изображения (включая RAW с камер: CR2/CR3, NEF, ARW, RAF, DNG, ORF, RW2 и др.), аудио, видео, PDF, документы, таблицы, презентации, субтитры и архивы. Доступные операции зависят от типа входного файла. **Pandoc 3.12.1 включён в архив**: конвертация DOCX, Markdown, HTML, EPUB, RTF и TXT не требует скачивания Pandoc. Распакуйте всю папку, включая `tools`. Для аудио и видео FFmpeg скачивается через настройки; LibreOffice для части операций Office/PDF устанавливается отдельно. Обработка файлов локальная.

## Сборка

Нужен .NET SDK 10. Сборка включает официальный Windows-пакет Pandoc с проверкой SHA-256; для этого нужен доступ к GitHub Releases. У конечного пользователя запросов к GitHub API для Pandoc нет. В PowerShell из папки проекта:

```powershell
./build.ps1
dotnet test tests/Sweetch.Tests -c Release
./publish/Sweetch.exe --self-test ./self-test
```

Для установщика нужен [Inno Setup 6 или 7](https://jrsoftware.org/isdl.php): после `build.ps1` выполните `./scripts/build-installer.ps1`. Результат появится в `artifacts/`.

GitHub Actions проверяет программу и установку, создаёт ZIP и установщик EXE с контрольными суммами и публикует их в релизе по тегу `v*`. Отдельный workflow **Publish installer for existing release** добавляет установщик к уже выпущенному ZIP, проверяя его SHA-256 и сохраняя файлы программы без изменений.
